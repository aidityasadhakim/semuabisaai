# One root environment file

Use the repository-root `.env` for local Vite, Docker development, and Docker production. Keep `CLERK_SECRET_KEY` server-side; only `VITE_CLERK_PUBLISHABLE_KEY` reaches the browser build.

1. Move all documented variables into root `.env.example` and remove the frontend template and setup step.
2. Point local Vite at the root env. Use same-origin `/api` requests, with Vite proxying to the local or Docker backend.
3. Build the production Caddy image with the public Clerk key from root Compose interpolation; exclude `.env` from the Docker build context.
4. Verify frontend build and lint, resolved Compose configs with synthetic values, and the production Docker build if the daemon is available.
